# 訊號深潛指南 | Signal Dive Guide

本頁說明訊號深潛的地圖圖例、房間地塊的作用、卡牌戰鬥的規則，以及戰鬥中出現的專有名詞。

每週輪替的異常協議請見 [每週異常協議](./signal-dive-anomaly)；裝備等級如何影響戰力請見 [綜合等級](./overall-level)。

---

## 1. 深潛流程

1. 在城市的地點選擇模式（探索／挑戰／駭入）與隊伍，建立深潛。難度由地點的等級範圍與模式決定。
2. 每場深潛有 3 幕，每幕是一張由房間組成的地圖。從入口出發，走過一般戰鬥、菁英、休息、商店等房間，最後擊敗本幕 Boss 進入下一幕。
3. 打完第 3 幕 Boss 即完整通關；部分情況可以選擇繼續挑戰無盡樓層。
4. 隊伍全員陣亡，深潛失敗。

## 2. 房間內的地塊

在房間內點擊格子即可移動，隊伍會自動繞開牆壁與尚未觸發的地塊。

| 外觀 | 名稱 | 作用 |
|------|------|------|
| 實心方塊 | 牆壁 | 無法通行 |
| 綠色箭頭 | 出口 | 走到這裡前往相鄰房間 |
| 紅色門 | 鎖住的門 | 戰鬥房尚未清空，先擊敗本房敵人 |
| `~` | 泥濘 | 移動變慢 |
| `»` | 輸送帶 | 移動變快 |
| `%` | 敵人 | 走上去開始戰鬥；擊敗前門會鎖住 |
| `♛` | Boss | 本幕 Boss，擊敗後前往下一幕 |
| `⬢` | 補給箱 | 全隊每位存活成員獲得 Swap（數量依幕數、模式與每週異常而定） |
| `‡` | 陷阱 | 全隊扣 6% 最大 HP，不會致死 |
| `◈` | 修復節點 | 全隊回復 15% 最大 HP |
| `？` | 地下城任務 | 接下本幕任務，擊敗本幕 Boss 時判定 |
| `$` | 商店 | 走上去開啟商店；每間商店只能開一次 |
| `！` `◆` `♨` | 房間設施 | 事件、寶箱、休息點，進入房間時開啟 |

每個地塊整隊只能觸發一次，觸發後會變灰。

### 2.1 地下城任務

每幕可能有一個任務。踩到 `？` 接下任務後，擊敗本幕 Boss 時依條件判定，成功可獲得額外 Swap。

| 任務 | 條件 |
|------|------|
| 清除所有戰鬥房間 | 本幕所有一般、菁英與 Boss 房都打過 |
| 不踩任何陷阱 | 本幕沒有觸發陷阱 |
| 打開所有補給箱 | 本幕所有補給箱都開過 |

## 3. 全幕地圖

畫面右側（或下方）的小地圖顯示本幕所有房間。

| 符號 | 意思 |
|------|------|
| `●` | 目前位置 |
| `+` | 尚未探索的房間 |
| `⌂` | 入口 |
| `%`（紫） | 一般戰鬥 |
| `%`（橙） | 菁英戰鬥 |
| `♛` | Boss |
| `！` | 事件 |
| `◆` | 寶藏 |
| `$` | 商店 |
| `♨` | 休息 |
| `⚑` | 隊友插旗（想去的房間） |

可以點小地圖上相鄰的房間直接移動。

## 4. 多人深潛

- 一場深潛最多 3 人，隊友可在途中透過房號、房間列表或聊天室分享加入。
- **領航員**：只有領航員能移動、開門、踩地塊與開戰。房主可以指派任何存活隊友擔任領航員。
- **插旗**：其他隊友點地圖會插旗，表示想去哪個房間。
- **接手**：領航員閒置太久時，插了旗的隊友可以接手帶隊。
- 戰鬥中每人各自出牌，全員結束回合後敵人才行動；敵人每次行動會隨機選一位存活玩家當目標。
- 隊伍人數越多，敵人的 HP 與傷害越高。

## 5. 戰鬥規則

### 5.1 回合流程

1. **你的回合開始**：護盾歸零（有「路障」除外）、能量補滿、抽 5 張牌。
2. **出牌**：每張牌左上角是能量費用，能量足夠就能打出。
3. **結束回合**：手牌全部棄掉（「保留」的牌除外，「虛無」的牌會被消耗）。
4. **敵人回合**：每個敵人依頭上顯示的**意圖**行動。
5. 有持續回合數的狀態（暴露、降頻、脆化等）在回合結束時減 1。

### 5.2 基本數值

| 項目 | 說明 |
|------|------|
| HP | 歸零即陣亡。最大 HP 由主控英雄的職業、護甲與戰力倍率決定 |
| 能量 | 每回合 3 點，用來打出卡牌 |
| 抽牌 | 每回合 5 張，手牌上限 10 張 |
| 護盾 | 先替你吸收傷害，你的回合開始時歸零 |
| 戰力倍率 | 深潛開始時由綜合等級換算，放大卡牌傷害、護盾、詞綴數值與最大 HP |

### 5.3 傷害與護盾的計算

```text
攻擊傷害 = (卡面數值 × 戰力倍率 + 出力) × 降頻 0.75（若有）× 暴露 1.5（若目標有）
獲得護盾 = (卡面數值 × 戰力倍率 + 反應) × 脆化 0.75（若有）
```

卡面上顯示的數字已經算好上述加成，是實際會造成的數值。選好卡但尚未打出時，畫面會預覽目標打完後的 HP 與護盾。

### 5.4 牌堆

| 牌堆 | 說明 |
|------|------|
| 抽牌堆 | 尚未抽到的牌；抽完時把棄牌堆洗回來 |
| 棄牌堆 | 打出或回合結束棄掉的牌 |
| 消耗堆 | 被「消耗」的牌，本場戰鬥不會再回來 |

### 5.5 卡牌種類

| 種類 | 說明 |
|------|------|
| 攻擊 | 對敵人造成傷害 |
| 技能 | 防禦、抽牌、施加狀態等 |
| 能力 | 打出後在本場戰鬥持續生效 |
| 支援 | 支援英雄提供的指令 |
| 雜訊／病毒 | 敵人塞進你牌組的無用牌，通常不可打出 |

名稱後面有「+」代表已升級的卡牌，數值更高。

### 5.6 卡牌關鍵字

| 關鍵字 | 意思 |
|------|------|
| 消耗 | 打出後移出本場戰鬥 |
| 保留 | 回合結束時不會被棄掉 |
| 虛無 | 回合結束時還在手上就會被消耗 |
| 固有 | 戰鬥開始時必定在起手 |
| 不可打出 | 無法打出 |

### 5.7 敵人意圖

敵人頭上的圖示與數字代表下一回合要做的事：攻擊（顯示傷害與段數）、防禦、強化、減益、召喚、分裂、沉睡等。看到「意圖不明」時，代表無法預測。

## 6. 狀態一覽

### 6.1 常見狀態

| 狀態 | 效果 |
|------|------|
| 出力 | 攻擊每段傷害 +N |
| 反應 | 卡牌獲得的護盾 +N |
| 暴露 | 受到的攻擊傷害 +50%，剩 N 回合 |
| 降頻 | 造成的攻擊傷害 −25%，剩 N 回合 |
| 脆化 | 卡牌獲得的護盾 −25%，剩 N 回合 |
| 侵蝕 | 回合開始時失去 N HP，然後層數 −1 |
| 蓄勢 | 本回合下一張攻擊牌每段傷害 +N |
| 防火牆 | 抵銷接下來 N 個負面狀態 |
| 相位 | 每次失去的 HP 降為 1，剩 N 回合 |
| 裝甲化 | 回合結束時獲得 N 點護盾 |
| 路障 | 護盾不會在回合開始時消失 |
| 反制電路 | 受到攻擊時，對攻擊者造成 N 點傷害 |
| 修復迴圈 | 回合結束時恢復 N HP |
| 自我修復 | 戰鬥結束時恢復 N HP |
| 鎖定 | 本回合無法打出攻擊牌 |

### 6.2 延遲效果

| 狀態 | 效果 |
|------|------|
| 預載護盾 | 下回合開始時獲得 N 點護盾 |
| 預取 | 下回合多抽 N 張牌 |
| 能量預存 | 下回合多 N 點能量 |
| 出力衰退 | 回合結束時失去 N 出力 |

### 6.3 能力牌帶來的狀態

| 狀態 | 效果 |
|------|------|
| 殘影 | 每打出一張牌，獲得 N 點護盾 |
| 惡魔核心 | 回合開始時獲得 N 出力 |
| 超頻 | 每回合獲得 N 出力 |
| 過載核心 | 回合開始時獲得 N 點能量 |
| 根權限 | 回合開始時多抽 N 張牌 |
| 回聲 | 本回合接下來 N 張攻擊牌打出兩次 |
| 放大 | 本回合接下來 N 張能力牌打出兩次 |
| 回響形態 | 每回合前 N 張牌打出兩次 |
| 腐化協定 | 技能牌費用為 0，打出後消耗 |
| 附毒 | 攻擊造成未被護盾擋下的傷害時，施加 N 侵蝕 |
| 毒霧 | 回合開始時，所有敵人獲得 N 侵蝕 |
| 獵殺本能 | 對暴露的敵人，攻擊每段傷害 +N |
| 無痛 | 每當一張牌被消耗，獲得 N 點護盾 |
| 火焰屏障 | 本回合受到攻擊時，對攻擊者造成 N 點傷害 |
| 散熱邏輯 | 每打出一張能力牌，抽 N 張牌 |
| 無限刃 | 回合開始時，將 N 張彈片加入手牌 |
| 精準 | 彈片傷害 +N |
| 重裝 | 每當你獲得護盾，對隨機敵人造成 N 點傷害 |
| 反應裝甲 | 每當被施加負面狀態，獲得 N 點護盾 |
| 破裂 | 每當卡牌讓你失去 HP，獲得 N 出力 |
| 全域中繼 | 回合結束時不棄手牌 |
| 預先規劃 | 回合結束時保留 N 張手牌 |
| 電湧 | 本回合每打出一張技能牌獲得 1 點能量（剩 N 次） |

### 6.4 敵人專屬狀態

| 狀態 | 效果 |
|------|------|
| 激怒 | 你每打出一張技能牌，牠獲得 N 出力 |
| 模式切換 | 再受到 N 點傷害就切換成防禦模式 |
| 沉睡 | 受到傷害或 N 回合後甦醒 |
| 時間扭曲 | 你再打出 N 張牌，就會強制結束回合並讓牠獲得 2 出力 |
| 爆散 | 死亡時，對其他敵人造成等於其最大 HP 的傷害 |

## 7. 深潛中的資源

| 名稱 | 說明 |
|------|------|
| 存取權杖 | 本場深潛專用的貨幣，在商店購買卡牌、通訊協定與調諧器，或使用維護服務。深潛結束後不保留 |
| 通訊協定 | 被動加成，取得後整場深潛持續生效。核心協議每回合 +1 能量，但各有代價 |
| 調諧器 | 戰鬥中使用的消耗品（例如回復 HP、造成傷害、施加暴露），最多帶 3 個 |
| 詞綴協議 | 護甲詞綴在戰鬥中觸發的效果，每次觸發會消耗主電池電力 |
| 主電池 | 上下身護甲共用的電力池；電力耗盡時詞綴協議停止運作，護甲的基礎 HP 不受影響 |

### 7.1 特殊房間

| 房間 | 說明 |
|------|------|
| 休息（維護節點） | 擇一：回復 HP、升級一張牌，或移除一張牌 |
| 商店 | 用存取權杖購買卡牌、通訊協定與調諧器，或付費移除一張牌 |
| 事件 | 二選一的劇情事件，各有獎勵與代價 |
| 寶藏 | 開啟寶箱獲得獎勵 |
