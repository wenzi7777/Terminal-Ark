# 額定能耗 | Rated Power Draw

本頁說明護甲能耗的計算方式、戰鬥引擎的實際扣電規則，以及主電池的供給與補充機制。

介面標示的「額定能耗」為**規格值**，用途是裝備之間的橫向比較，不代表單場戰鬥的實際消耗量。實際消耗由第 3 節的引擎規則決定，可能高於或低於此值。

---

## 1. 定義

```
額定能耗 = Σ（該護甲原生詞綴的電力成本） + Σ（其插槽模組詞綴的電力成本）
```

即「該護甲上所有詞綴各啟用一次」所需的電力總和。計算範圍僅限單一護甲及其已裝配的升級模組；上下身護甲各自獨立計算，介面另行提供兩者合計。

### 1.1 計費範圍

| 項目 | 是否計費 |
|------|----------|
| 護甲基礎倍率（輸出、防護、完整性） | 否 |
| 護甲原生詞綴 | 是 |
| 插槽模組詞綴 | 是 |

基礎倍率不依賴電力供給。在無電池或電力耗盡的狀態下，護甲基礎數值仍完整生效，僅詞綴與模組效果停止運作。

---

## 2. 詞綴電力成本表

| 成本 | 詞綴 |
|------|------|
| 1 | 精準模組、動力補償、防護、動能屏障、奈米縫合、吸血核心 |
| 2 | 高能電容、陣列護盾、加密鏈路、循環劫持、相位破壞、奧術透鏡 |
| 3 | 自動迴避、零場 |

**計算範例**

| 來源 | 詞綴 | 成本 |
|------|------|------|
| 上身護甲原生 | 陣列護盾 | 2 |
| 上身護甲原生 | 精準模組 | 1 |
| 插槽模組 | 零場 | 3 |
| **合計** | | **6** |

---

## 3. 實際消耗與估算值的差異

戰鬥引擎採逐次計費，與第 1 節的靜態加總存在四項系統性差異。

### 3.1 同名詞綴去重

同一詞綴同時存在於上身、下身或插槽模組時，引擎僅保留**效果強度最高**的一份，並僅對該份計費。額定能耗不執行去重，因此在重複配置下會**高於**實際消耗。

### 3.2 持續型與事件型的計費時機

| 類型 | 適用詞綴 | 計費時機 |
|------|----------|----------|
| 持續型 | 動力補償、防護、加密鏈路 | 建立戰鬥時一次性扣除，效果持續整場 |
| 事件型 | 其餘全部詞綴 | 每次實際觸發時各扣除一次 |

事件型詞綴在長時間戰鬥中可能觸發多次，此情形下實際消耗將**高於**額定能耗。

> 加密鏈路同時決定角色最大 HP。建立戰鬥時若電力不足以支付其成本，該場戰鬥的最大 HP 計算不納入此詞綴。

### 3.3 無效觸發不計費

事件型詞綴僅在觸發條件成立、且確實改變戰鬥狀態或產生戰鬥事件時才扣除電力。條件未成立的空轉不計費。

### 3.4 電力不足時整條略過

單一效果的電力不足時，該效果**完全不生效**，亦不扣除電力；引擎不執行按比例削弱。

---

## 4. 供電順序

電力不足時，引擎依固定順序配電，先處理者優先取得電力：

1. 上身護甲原生詞綴
2. 上身護甲插槽模組
3. 下身護甲原生詞綴
4. 下身護甲插槽模組

此順序為確定性的，同一組裝備在每場戰鬥中的取捨結果一致。電力預算緊張時，將關鍵詞綴配置於上身可確保其優先供電。

---

## 5. 主電池

每名玩家僅裝備一顆主電池，上下身護甲與全部插槽模組共用其電力。電池不隸屬於任何一件護甲，更換護甲不影響電池配置。

| 稀有度 | 最大電力 | 總充電額度 |
|--------|----------|------------|
| 破損 | 100 | 200 |
| 普通 | 130 | 390 |
| 稀有 | 170 | 680 |
| 傳說 | 220 | 1320 |
| 史詩 | 480 | 2880 |

- **最大電力**：單次出擊可用的電力上限。
- **總充電額度**：該電池剩餘的可補充電力總量，屬不可逆耗材。每補充 1 點電力即扣除 1 點額度；額度歸零後電池永久損毀，無法修復。

---

## 6. 戰鬥託管與結算退還

進入訊號深潛或限時地下城時，主電池的全部電力於同一筆交易內託管至該次探索，持久化電量暫時歸零。此為預期行為。

結算、戰敗、離開或放棄時，未消耗的整數電力原封退還。退還機制以電池上的託管標記為依據，具冪等性：勝負結算、逾時清理與重送請求均只會退還一次。

託管期間該電池無法卸下、交換、充電或回收。

---

## 7. 充電站

充電由荒原開發終端第二列的固定充電站提供。該設施不佔用建築點，不可拆除，可升級至 Lv.4。

| 等級 | 充電槽 | 每 1 點電力所需時間 |
|------|--------|---------------------|
| Lv.1 | 1 | 1 分鐘 |
| Lv.2 | 2 | 0.75 分鐘 |
| Lv.3 | 2 | 0.5 分鐘 |
| Lv.4 | 3 | 0.25 分鐘 |

### 7.1 代理人加成

充電站可派駐一名代理人，其核能研究專精加成充電速率：

```
有效每點時間 = 基礎每點時間 ÷ (1 + 核能研究加成)
```

### 7.2 速率鎖定

設施等級與代理人加成於**開單當下快照**，並在該筆訂單存續期間固定不變。後續的代理人異動、設施升級或心情變化均不影響進行中的訂單。若需套用新的加成，須取回電池後重新放入。

充電不需派駐代理人，亦不消耗代理人心情。

### 7.3 結算規則

取回時僅結算已完成的整數電力，未滿一點的部分不予保留。若送入充電的電池為當前裝備中的主電池，系統於同一次操作內將其卸下。

---

## 8. 判讀注意事項

| 現象 | 說明 |
|------|------|
| 額定能耗顯示為 0 | 該護甲與其模組均未配置需要電力的詞綴，僅有基礎倍率生效。屬正常狀態。 |
| 電池為滿電，仍有詞綴未生效 | 應檢查兩項：該詞綴是否在供電順序中被前序項目耗盡電力（第 4 節）；上下身是否配置了同一詞綴而觸發去重（第 3.1 節）。 |
| 探索中顯示的電力與背包不一致 | 探索期間電力已託管至該次探索，顯示值為該次探索的剩餘量；背包持久化電量在此期間為 0，結算後退還（第 6 節）。 |
| 回收電池的產出 | 回收產出僅依稀有度決定，與剩餘電力及剩餘充電額度無關。先行充電再回收不會提高產出。 |
