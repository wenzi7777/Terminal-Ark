# Terminal Ark Changelog

## APP BUNDLE VERSION v0.13.1 Public Beta
## SERVER BUNDLE VERSION v0.13.1 Public Beta

## Release Date: Oct. 22nd 2026 22:00 JST

### Changelog
- Room events now trigger only when you step on their tile, and the tile dims once used.
- Fixed a sync bug that sometimes snapped you back to the door while walking in a room.
- Stepping on a quest tile now opens a prompt to accept or decline the quest.
- Combat rooms now hold several enemies, including weaker patrols, and the doors open only when all are defeated.
- “Signal Dive” is now “Dungeon”, and old links redirect automatically.
- Quest info now appears only after you accept a quest, with no more “quest available” banner.
- Added two new quest types: Bounty and Low-Damage Clear.
- Dungeon rooms are now drawn with plain characters (# walls, . floor) instead of textures.
- Finished output can be collected even with no agent assigned or mood depleted.
- Trading delivers whatever you can afford and the card says when materials are short.
- Card, quick button, to-do dock and home tile share one “ready” rule.
- Facilities keep working at zero mood; only skills switch off.
- Mood drains only while a facility is actually working.
- Idle heroes recover 3 mood per hour.
- Live mood with time-to-empty/full forecasts and low-mood warnings.
- New “Shift change” swaps exhausted agents for rested, best-fit heroes.
- Agent skills rebuilt: 20 facility-bound skills with α/β grades and Rank unlocks.
- Agent picker sorts by facility fit and moves heroes between facilities directly.
- The Super Terminal now supplies power, so new bases are no longer short.
- Nuclear plant level raises charge rate (12/16/20/24 per hour).
- Guaranteed rest rooms are now fixed facilities.
- Building points hidden; base power impact previewed instead.
- Confirmations before cancel, discard, and early battery removal.
- Fixed double-collect, double-refund and free-acceleration exploits.
- Processing warns about missing agent or power before starting, with an assign shortcut.
- Trading strategy is now saved per trading station.
- Expeditions no longer show a reward estimate until completed.
- Every speed-up opens a quantity picker with +1, +10 and “Finish now”.
- “Command Points” renamed to “Overload Capacitors” with a new icon.
- Quick-action labels drop the “One-tap” prefix.
- Agent cards redesigned: no particles, data-card layout with mood forecasts.
- Info icon on cards and the standard segmented tabs for sorting.
- Facility slots redesigned as cut-corner tiles with facility color band, watermark, and progress edge.
- Facility detail header redesigned as a hero tile with level pips.
- Reception room redesigned: nearby target is now a single card with a primary action, reward quota pinned to the header, scene display settings in their own section.
- Agent cards now show a mood bar, depletion/refill forecast, and skill value chips.
- Recipe cards and picker restyled; current recipe selection highlight fixed.
- Negotiation strategy card adds an explicit “Change” button; strategy list marks the current one.
- Paused orders now show the reason (no agent / insufficient power) with an assign shortcut.
- Pending deliveries use a color rail to show deliverability.
- Processing setup uses spec cells and a single blocker card; storage and raw materials shown side by side.
- “Signal Scan” heading localized in all four languages.
- Info Trade bonus is now rolled on delivery, so cancel-and-restart no longer farms it.
- Trading and Processing Station levels now raise storage and speed (up to +15%).
- Advanced Cache Data now costs 1,500 Memory + 32 Brand New Parts, 2h to process.
- Classified Convoy orders now turn 2 data blocks into 60 Swap.
- Cancelling processing refunds Memory for unfinished units.
- Processing UI shows the Memory cost and blocks start when Memory is short.

### Others
- Included various minor fixes and performance optimizations.
