# Terminal Ark Changelog

## APP BUNDLE VERSION v0.13.2 Public Beta
## SERVER BUNDLE VERSION v0.13.2 Public Beta

## Release Date: Oct. 25th 2026 21:30 JST

### Changelog
- Updated the Ark server hack ranking: tapping a player opens terminal actions. The ranking is paginated with 10 players per page, covering the top 100.
- Reworked the High-Efficiency Power Converter into a Personal Amplifier, including a matching crafting recipe and a new icon.
- Added a new **Chips** inventory tab for Cognition, Void Cognition, and Expansion Chips.
- Fixed mood consumption: completed but uncollected orders no longer consume Mood, and the on-screen Mood value stops decreasing when an order finishes.
- Redesigned dungeon mode selection with tabs and a detail card displaying threat level, rewards, and hack cost.
- Fixed an issue where the first card in the hand was clipped when scrolled all the way to the left.
- Updated dungeon supply crate rewards to grant 10/15/20 Swap per act, multiplied by the selected mode's multiplier.
- Replaced remaining references to “Signal Dive” and “dive” with “Dungeon.”
- Updated dungeon enemy rewards: patrols now grant a General Crate plus 60% of the usual Memory and EXP rewards, while the main enemy is now a Mini-boss that grants full rewards. General rooms now contain 2–3 enemies, while elite rooms contain 3.
- Fixed untranslated `{{turns}}` placeholders in enemy intent text.
- Pages matching `disc/*` now remember your last selection.
- Added a music player and background music.
- Added maintenance mode.

### Others
- Included various minor fixes and performance optimizations.
