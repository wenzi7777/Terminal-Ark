# Terminal Ark Changelog

## APP BUNDLE VERSION v1.0.1 Public Stable
## SERVER BUNDLE VERSION v1.0.1 Public Stable

## Release Date: Nov. 3rd 2026 4:20 JST

### Changelog
- Introduced **Terminal Anti-Cheat (TAC)**, a new system that protects the game economy and keeps automated scripts out.
- Added the **Neural Signal Check**, a short in-game verification. It appears before creating a guest account or sending a login code, and occasionally when the terminal detects an unusual input rhythm. There are five check types: Guard Hack, Voltage Hold, Signal Trace, Sweep, and Converge. Every check is newly generated by the server, starts only after you press Start, and can be played with one large button or the Space key.
- Added **Neural Network Terminal Calibration** to dungeons. After using your neural network terminal for a while in a dungeon, its sync level drops and a calibration is required before you can keep moving. A successful calibration grants Swap equal to a supply crate (half for a partial success). A failed calibration leaves your connection unstable for the next battle, making enemies tougher.
- Reworked the newbie tutorial into a two-room tutorial dungeon. The tutorial can now be completed only once per account.
- Gifting items, listing or buying on the market, and giving prestige now require a non-guest account that is at least 3 days old. Bind an email to lift the guest restriction.
- You can now send up to 10 gifts per day. Gifts to yourself are no longer allowed.
- Market listings for items must now be priced within a range based on recent trades of the same item. You can no longer buy your own listings.
- Guest accounts can claim the app install reward after binding an email.
- Story acts must now be completed in order.
- Only the party leader can abandon a dungeon run. Other members can leave the run instead.
- Chat now allows up to 5 messages every 10 seconds, and redeem code attempts are limited to 10 per hour.
- Buttons now respond only to real clicks, taps, and key presses.
- Account restrictions are now shown in your personal buff list, including what is restricted and when it ends.
- Fixed several issues that could be exploited to predict battle draws and rewards or to claim rewards repeatedly.
- Fixed an issue where the offline cache could interfere with requests to other services.

### Others
- Included various minor fixes and performance optimizations.
