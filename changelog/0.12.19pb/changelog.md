# Terminal Ark Changelog

## APP BUNDLE VERSION v0.12.19 Public Beta
## SERVER BUNDLE VERSION v0.12.19 Public Beta

## Release Date: Sep. 30th 2026 21:30 JST

### Changelog
- Fixed a UI issue with the HomeUserBar.
- When editing facility agents, assigned agents now appear first, and agents in Sleep Pods can be reassigned with a single tap.
- Added a ToDo bar to the Wasteland Terminal, allowing players to collect, deliver, decode, or retrieve outputs from all facilities of the same type with a single tap.
- The Wasteland Development Terminal card on the Home page now displays a red dot when outputs are ready to collect.
- The Wasteland Development Terminal ToDo bar now flags agents with depleted mood; tapping it highlights all affected facilities.
- The Manufacturing Station agent strip is now a single tappable card that opens agent selection.
- Fixed an issue where collecting rewards from the Execution Machine could display an error after rewards were granted without consuming mood, and prevented duplicate claims.
- When assigning agents to a Sleep Pod, agents currently working in other facilities can now also be selected.

### Others
- Included various minor fixes and performance optimizations.

***This is a hotfix update and will be installed automatically. You will receive a notification prompting you to refresh the page after the hotfix is installed.***
